# Contributing to Overwatch GEOINT

First off, thank you for considering contributing to Overwatch GEOINT! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## How to Contribute

1. **Fork the Repository**: Start by forking the repo to your own GitHub account.
2. **Clone the Repo**: Clone it locally to your machine.
3. **Create a Branch**: Always create a new branch for your feature or bugfix (`git checkout -b feature/amazing-feature`).
4. **Make your Changes**: Implement your feature or bug fix.
5. **Run Tests & Linting**: Ensure `pytest` passes and the code complies with PEP-8 (`flake8` / `black`).
6. **Commit your Changes**: Write clear and meaningful commit messages.
7. **Push to your Fork**: Push the branch to your GitHub repository.
8. **Open a Pull Request**: Submit a PR to the main repository using the provided template.

## Development Environment
Please refer to the `README.md` for instructions on setting up your local Python, Docker, and Terraform environment.

## Code Review Process
All pull requests will be reviewed by the maintainers. We may ask for changes or tests to be added before merging.
